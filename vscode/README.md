# DSH Companion for VS Code

An independent community project built on DeepSeek Harness. This project is not affiliated with or endorsed by DeepSeek.

Open the DSH Companion activity-bar view to browse Sessions in the current workspace, optionally search all workspaces, reopen a closed chat (other paths focus or open the matching VS Code window after confirmation), open a new draft, or manage providers; **DSH: New Chat Editor** provides the same draft action from the Command Palette. A new tab creates its DSH Session only with the first prompt. The current preview supports pasted user images, streaming text, Markdown with clickable local file/line links, Turn activity, model and Session-permission selection, native provider settings, usage and available monetary accounting, Session and Runtime information, Stop, restoration of open editor tabs, and an internal Linux Managed Runtime package.

See [the feature reference](../features.md) for current behavior and limitations.
