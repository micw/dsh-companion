# DSH Companion for VS Code

An independent community project built on DeepSeek Harness. This project is not affiliated with or endorsed by DeepSeek.

Open the DSH Companion activity-bar view to browse DSH Sessions, search their questions and answers, reopen a closed chat, open a new draft, or manage providers; **DSH: New Chat Editor** provides the same draft action from the Command Palette. A new tab creates its DSH Session only with the first prompt. The current preview supports streaming text, Markdown, Turn activity, model and Session-permission selection, native provider settings, usage and available monetary accounting, Session and Runtime information, Stop, restoration of open editor tabs, and an internal Linux Managed Runtime package.

See [the feature reference](../features.md) for current behavior and limitations.
