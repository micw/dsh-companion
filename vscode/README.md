# DSH Companion for VS Code

An independent community project built on DeepSeek Harness. This project is not affiliated with or endorsed by DeepSeek.

Run **DSH: New Chat Editor** from the Command Palette to create a DSH-backed chat editor for the current workspace. The current proof of concept supports streaming text, Markdown, Turn activity and usage, Stop, and restoration of open editor tabs.

See [the feature reference](../features.md) for current behavior and limitations.
