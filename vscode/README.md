# DSH Companion for VS Code

An independent community project built on DeepSeek Harness. This project is not affiliated with or endorsed by DeepSeek.

Open the DSH Companion activity-bar view to browse Sessions in the current workspace, optionally search all workspaces, reopen a closed chat (other paths focus or open the matching VS Code window after confirmation), open a new draft, or open **DSH: Settings**. The reusable Settings editor manages models and web-search accesses for the connected Runtime independently of chats. **DSH: New Chat Editor** provides the draft action from the Command Palette; a new tab creates its DSH Session only with the first prompt. The current preview supports pasted user images, streaming text, Markdown with clickable local file/line links, Turn activity, model and Session-permission selection, usage and available monetary accounting, Session and Runtime information, Stop, restoration of open editor tabs, and an internal Linux Managed Runtime package.

See [the feature reference](../features.md) for current behavior and limitations.
