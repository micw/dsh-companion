# DSH Companion for VS Code

An independent community project built on DeepSeek Harness. This project is not affiliated with or endorsed by DeepSeek.

Run **DSH: New Chat Editor** from the Command Palette to create a DSH-backed chat editor for the current workspace. The current preview supports streaming text, Markdown, Turn activity, model and Session-permission selection, native provider settings, usage and available monetary accounting, Session and Runtime information, Stop, restoration of open editor tabs, and an internal Linux Managed Runtime package.

See [the feature reference](../features.md) for current behavior and limitations.
